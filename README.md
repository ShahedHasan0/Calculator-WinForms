# Calculator

A Windows Forms App (.NET Framework) calculator made in Visual Studio 2022.

## Features
- Dynamic GUI generated from C# code
- Standard calculator mode
- Scientific calculator mode
- Memory buttons
- Basic and scientific calculations

## Technologies
- C#
- Windows Forms
- .NET Framework
- Visual Studio 2022

## How it works
The calculator controls are generated dynamically at runtime using source code.  
The app rebuilds the button layout when switching between Standard and Scientific modes.
